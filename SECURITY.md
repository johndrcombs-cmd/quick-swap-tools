# Security Policy

## Supported versions

The latest release is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository rather than opening a public issue. Include the affected version, impact, reproduction steps, and any suggested mitigation.

Do not include Mozilla signing credentials, private Whatnot URLs, account details, or other secrets in reports.

Quick Swap Tools deliberately fails closed when a page control is hidden, disabled, covered, missing, or ambiguous. Reports showing a path that bypasses those checks are especially important.
